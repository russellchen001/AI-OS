# AI-OS 1.0.1-beta.4

Beta.4 adds the Adaptive Context & Knowledge Engine.

- Long conversations now preserve important decisions, requirements and numbers
  with traceable message identities while keeping the complete original history.
- Full conversation history can be searched and relevant prior messages can be
  retrieved inside the current project boundary.
- Project knowledge workspaces accept explicitly selected PDF, Word, PowerPoint,
  Excel, text and code sources. Retrieval stays local, bounded and source cited.
- P14 Memory, project knowledge and model-aware context budgets are combined at
  request time without changing Task Engine, Planner or Runtime authority.
- GPT, Claude, oMLX and Auto continue through AI Center; unknown context limits
  fail closed to 32,000 tokens.

This is a local release candidate. It has not been pushed, tagged, notarized or
published, and no paid cloud-provider acceptance is claimed.
